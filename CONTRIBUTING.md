# Règles de contribution (simples)

Merci de contribuer.

## ✅ Règle principale
- **Interdiction de pousser directement sur `main`**
- Toute modification passe par une **Pull Request (PR)**
- **Seul le chef de projet (Jimmy-Network1)** valide et fusionne

## 🔁 Processus simple
1. Créer une branche
2. Faire les modifications
3. Pousser la branche sur GitHub
4. Ouvrir une Pull Request vers `main`
5. Attendre la validation du chef de projet

Merci de respecter ces règles pour garder le projet propre et stable.
